# アフィリエイト情報サイト向け HTML/CSS テンプレート集

本リポジトリは、主にアフィリエイトや情報発信サイトでの使用を想定した、汎用性の高いHTML/CSSテンプレート集です。
ページの目的や商材に応じた「レイアウト（デザインコンセプト）」と、それにマッチした「装飾（デザインテイスト）」を組み合わせた6パターンの完成版テンプレートを提供しています。

## 2. 特徴・カスタマイズ方法

### 🎨 CSS変数による簡単カラー着せ替え
本テンプレートは、CSSで配色（カラーバリエーション）を簡単に変更できるよう設計されています。
各テンプレートの `style.css` の冒頭にある `:root` にて、テーマカラーをCSSカスタムプロパティ（CSS変数）で定義しています。

```css
:root {
  /* ここを好みのカラーコードに書き換えるだけで、サイト全体の配色が切り替わります */
  --color-primary: #0a2540;       /* メインカラー */
  --color-accent: #d4af37;        /* アクセント・CVカラー */
  --color-text-main: #2b3a4a;     /* テキストカラー */
  --color-bg-soft: #f4f6f8;       /* 背景カラー */
  ...
}
```

### 📱 レスポンシブ対応
すべてのテンプレートはモバイルファーストでコーディングされており、スマートフォン（375px〜）からデスクトップ（1200px〜）まで、表示崩れなく綺麗に自動調整されます。
特に、スマホで表示が崩れがちな「比較テーブル」は、横スクロールに対応させています。
